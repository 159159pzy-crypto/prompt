槽位 [detail/mood]。质感/运动/氛围各选 1 个。
质感：ink splash / comic / sketch / painterly / film grain / greyscale。
运动：motion lines / speed lines / motion blur（冲刺阶段）。
数字：glitch / VHS / chromatic aberration（赛博/催眠/偷拍才用）。
氛围：cinematic / dramatic tension / ethereal / dark atmosphere / poetic atmosphere。
禁止光线/光影/色调（banlist.py 为唯一真源），包括 backlit、chiaroscuro、dramatic shadows。允许天气与时辰；允许 lens flare、bloom 作为镜头光学。
